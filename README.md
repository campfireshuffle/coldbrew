## Introduction

A visual interface to quickly install your favorite macOS apps from Homebrew Cask

![Coldbrew: a searchable grid of popular Homebrew casks with install counts](assets/preview.webp)

## Stack

- Cloudflare Workers
- Cloudflare D1
- Cloudflare KV
- Next.js
- Tailwind CSS
- Prisma
- TRPC
- TypeScript

## Local development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
